# Go2–Z1 全身规划可视化 demo

新增独立示例 `examples/go2_z1_whole_body_demo.py`，生成可直接在浏览器打开的
`artifacts/go2-z1-demo/index.html`。网页自包含，不安装渲染库、不联网，也不执行力矩。
支持播放/暂停、0.25×/0.5×/1×、时间轴、四个预设视角、拖动旋转和滚轮缩放。
播到终点会停止，重播从初始状态开始。

## 回放内容

使用已完成的 Go2–Z1 W CPU 规划器，独立求解一个 3 s、60 个控制节点的往返任务。
前 1.5 s 手端相对初始位置前伸 6 cm、侧移 12 cm、下降 3 cm，后 1.5 s 返回，
保持手端世界朝向。去程和返程一起优化，没有反转动画或人为放大动作。
其余代价和约束沿用 W 首版。这里只为更长的展示增加时域，不改变原规划器默认参数。

显示内容包括 Go2、支架、Z1、固定夹爪、虚拟 TCP、目标/预测路径、质心及其投影、
四足支撑区域和接触力。地面网格为 0.1 m；力箭头长度按 1 m = 400 N 显示，
足端标签显示法向力。实时读数为 TCP 位置误差、18 关节最大力矩占限值比例和最大足漂移。

Go2 和支架使用派生 URDF 中的碰撞几何；Z1 使用真实关节中心之间的简化连杆、关节球和
示意夹爪，未下载官方外观 mesh，也没有把示意几何写回动力学或碰撞模型。
几何位姿来自真实求解状态的 Pinocchio FK。浏览器在 61 个节点之间插值位置、四元数和读数，
只用于平滑显示；约束检查仍限于求解节点。

此 demo 是 **W 规划器的 CPU 刚体预测回放**。没有统一 WBC、物理引擎、外扰闭环或执行器
仿真，不能据此认定真实跟踪性能、碰撞可行性或实时控制能力已验收。

## 本机结果

2026-11-13，3 s 任务在 6 次 Box-FDDP 迭代后收敛，独立约束和任务跟踪检查通过。
TCP 预测位置 RMSE 0.0566 mm，峰值 0.0767 mm；足端最大漂移 2.22 μm；最大力矩占
URDF 限值 23.83%。摩擦、法向力、关节、速度及基座边界违反量均为零。
基座各方向位移范围约为 4.22、3.50、0.84 mm，画面采用真实尺度。

检查覆盖：

- 61 帧、44 个简化几何、49 维状态和 18 维控制数据；TCP/质心/足端与重新计算的 FK
  一致到导出精度 5.1e-9 m，力数据误差不超过 5.1e-7 N。
- 已安装 Edge 的临时空白配置中检查独立页面及对话内 iframe：播放、暂停、拖动时间轴、
  视角切换、浅色/深色、320 px 布局和到终点停止；无 JavaScript 错误。
- 对话内控件状态回传不再打断播放；未改变用户现有浏览器配置。
- 本轮开始前 103 个既有代码/资产/测试/示例/配置和 82 个依赖元数据文件哈希一致。
  不修改单 Go2 训练代码、W 求解器、模型或依赖环境。

求解和页面检查记录见 [demo 验收](benchmarks/go2_z1_demo_2026-11-13/summary.json)。
生成目录同时包含 `report.json`、`trace.json`、`scene.json` 和可视化片段 `replay.html`。
`artifacts/` 是本地产物，不纳入 Git；生成脚本和两个 HTML 模板可随代码提交。

## 复现

从仓库根目录运行，复用已经验证的独立 native 目录，不安装或升级依赖：

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONNOUSERSITE=1 \
OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 OMP_NUM_THREADS=1 \
PYTHONPATH=.dev-tools/crocoddyl321-pin400/cmeel.prefix/lib/python3.11/site-packages:src \
.venv/bin/python -B examples/go2_z1_whole_body_demo.py
```

然后用浏览器打开 `artifacts/go2-z1-demo/index.html`。
`--output` 可指定产物目录，`--fragment` 可另存对话内回放片段。
生成器只接受收敛且通过任务/约束检查的结果；失败时不会导出标为通过的 demo。
