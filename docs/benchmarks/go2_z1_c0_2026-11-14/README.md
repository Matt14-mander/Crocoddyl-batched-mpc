## 最终对照结果

TCP/姿态指标对当前活动 Guidance；最后一列另报相对原共同任务的偏差。

| 任务 | 接收 / 请求 | TCP 峰值 mm（W / C0） | 姿态峰值 rad（W / C0） | 原任务 TCP 峰值 mm（W / C0） |
| --- | --- | ---: | ---: | ---: |
| hold | 8/8（两者相同） | 0.0004 / 0.0029 | 0.000000 / 0.000010 | 0.0004 / 0.0029 |
| reach | 12/12（两者相同） | 0.0223 / 0.0217 | 0.000052 / 0.000053 | 0.2579 / 0.2590 |
| high_low | 24/24（两者相同） | 0.4484 / 0.4360 | 0.005017 / 0.005052 | 0.4484 / 0.4360 |
| failure | 8/12（两者相同） | 0.6047 / 0.6165 | 0.000254 / 0.000268 | 22.3481 / 22.3482 |
| expired | 9/10（两者相同） | 0.6414 / 0.6526 | 0.000277 / 0.000292 | 22.3158 / 22.3158 |

故障与过期任务主动回站立，因此对原任务约 22.3 mm 的偏离仍如实报告；“通过”指回退、
恢复及对当前安全参考的原闭环门槛通过，不能表述为停包期间仍在 5 mm 内跟踪原任务。
两方法高低任务误差接近；这五个固定支撑任务不支持宣称某种模型普遍优于另一种。
